# 后台管理控制台使用说明

管理员或部长登录后，点击页面右上角“进入管理后台”，也可直接访问 `/admin/overview`。普通成员和组长访问后台地址时会看到无权限提示，管理接口仍会在服务端返回 403。

## 功能范围

- **总览**：查看账号、角色、小组、未分组人员、任务和逾期统计。
- **账号**：搜索和分页查看账号，新建账号，修改姓名及启停状态。管理员还可修改角色、重置密码。
- **组织**：新建或重命名小组，设置成员职务和负责人，移出成员。
- **任务**：按关键字、小组、负责人、状态、截止日期和逾期状态筛选，查看详情、评论、附件及流转记录，调整负责人和处理验收。
- **审计**：按操作人和操作代码查询管理记录。
- **系统状态**：只读检查应用、数据库和附件目录，不提供服务器命令入口。

新建账号和管理员重置密码后，账号会在首次登录时被要求修改临时密码。临时密码只在重置响应中显示一次；保存并交给成员后应关闭提示。角色修改、停用、密码重置和小组关系变更会撤销相关账号的旧会话。

部长可管理日常人员资料、组织与任务，但不能修改角色、重置密码或管理管理员和部长账号。管理员不能停用自己、修改自己的角色或在后台重置自己的密码，本人应使用工作台中的“修改密码”。

## 校园网访问

本机部署将应用监听在 `0.0.0.0:8080`，MySQL 仍只监听 `127.0.0.1:3307`。同一校园网内的设备使用启动脚本显示的 WLAN 地址访问，例如 `http://10.208.168.252:8080`。校园网重新分配地址后，以启动脚本当次显示的地址为准。

首次开放端口时，以管理员权限运行 `deploy/enable-campus-access.ps1`。该规则只允许本地子网访问 TCP 8080，不开放数据库端口。当前阶段使用 HTTP，仅适合受控校园网试用；正式上线仍按部署文档配置 HTTPS。
